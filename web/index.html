Your notes are files you own

                    

                        The web editor signs in with GitHub and commits every save to your private
                        everfree-notes repository. The Mac app keeps the same notes as local Markdown files in
                        ~/Documents/EverFree and syncs them through git.
                    

                    

                        There is no EverFree account and no EverFree database. If this project disappeared
                        tomorrow, your notes would still be sitting in your repo as ordinary files.

Getting started

                

                    

                        
In the browser

                        
    
                            
  1. Open the web editor and sign in with GitHub — a one-time device code, no password.
    2. 
                            
  2. Connect your private everfree-notes repository. EverFree creates it if needed and never uses another repository.
    3. 
                            
  3. Start writing. Every save commits the note to your repository.
    4. 
                        

                    

                    

                        
On the Mac

                        
    
                            
  1. Download the DMG and open it. It's signed and notarized, so no Gatekeeper workarounds.
    2. 
                            
  2. Connect GitHub — and optionally Evernote, to import your old notebooks as Markdown.
    3. 
                            
  3. Write locally; every save syncs through git, so the web and mobile editors see the same workspace.
    4.

FAQ

                

                    

                        
Is it really free?

                        
Yes. EverFree is MIT-licensed open source. There's no account, no plan, and no trial.

                    

                    

                        
Where are my notes stored?

                        
In the browser: as Markdown files in your private everfree-notes GitHub repo. On the Mac: as local files in ~/Documents/EverFree, synced through git.

                    

                    

                        
Can I import from Evernote?

                        
Yes, in the Mac app. The setup wizard connects your Evernote account and converts notebooks to Markdown (using evernote2md).

                    

                    

                        
Does EverFree store my notes?

                        
There is no EverFree database. Notes sync directly between your browser and your GitHub repository.

                    

                    

                        
Is there a mobile version?

                        
Yes — everfree.vercel.app/mobile is a lightweight client for the same workspace, good for capture, reading, and light edits.
